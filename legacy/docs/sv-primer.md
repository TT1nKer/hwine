# SystemVerilog Primer for AI

This is a condensed reference for writing correct, synthesizable SystemVerilog.

## Type System

```systemverilog
logic [7:0]  a;           // 8-bit unsigned vector
logic [7:0]  b = 8'd42;   // with initial value
logic [31:0] c [0:15];    // array of 16 32-bit values
logic signed [7:0] d;     // signed vector

typedef logic [7:0] byte_t;
typedef enum logic [1:0] {IDLE, RUN, DONE} state_t;
```

Use `logic` for everything. SystemVerilog unifies `reg` and `wire`.

## Combinational Logic

```systemverilog
// simple assign
assign y = a & b;

// always_comb block (use when there are multiple assignments or cases)
always_comb begin
    y = a & b;
    if (sel) y = a | b;
end

// case
always_comb begin
    case (sel)
        2'b00: out = a;
        2'b01: out = b;
        default: out = '0;
    endcase
end
```

**Rule**: every variable assigned in `always_comb` must be assigned in every possible path (otherwise inferred latch — BAD).

## Sequential Logic

```systemverilog
always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        counter <= '0;
        valid   <= 1'b0;
    end else begin
        if (enable) counter <= counter + 1;
        valid <= enable;
    end
end
```

- Use `<=` (non-blocking) inside `always_ff` for flip-flops
- Use `=` (blocking) inside `always_comb` for combinational
- Reset should be synchronous unless you have a good reason

## State Machines

```systemverilog
typedef enum logic [1:0] {
    S_IDLE  = 2'b00,
    S_BUSY  = 2'b01,
    S_DONE  = 2'b10
} state_t;

state_t state, next_state;

always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) state <= S_IDLE;
    else state <= next_state;
end

always_comb begin
    next_state = state;  // default: stay
    case (state)
        S_IDLE: if (start) next_state = S_BUSY;
        S_BUSY: if (done)  next_state = S_DONE;
        S_DONE: next_state = S_IDLE;
        default: next_state = S_IDLE;
    endcase
end
```

Pattern: separate next-state logic (combinational) from state register (sequential).

## Module Declaration

```systemverilog
module counter #(
    parameter WIDTH = 8
) (
    input  logic             clk,
    input  logic             rst_n,
    input  logic             enable,
    output logic [WIDTH-1:0] count
);
    // body
endmodule
```

## Testbench (Verilator C++)

Verilator compiles your SystemVerilog module into a C++ class. You write a C++ testbench that instantiates it, toggles inputs, and reads outputs.

```cpp
#include "Vtop.h"        // generated by Verilator
#include "verilated.h"
#include "verilated_fst_c.h"

int main(int argc, char **argv) {
    Verilated::commandArgs(argc, argv);

    Vtop *top = new Vtop;
    VerilatedFstC *tfp = new VerilatedFstC;
    top->trace(tfp, 99);
    tfp->open("build/sim.fst");

    top->clk = 0;
    top->rst_n = 0;
    top->eval();

    for (int i = 0; i < 100; i++) {
        top->clk = !top->clk;
        top->eval();
        tfp->dump(i);
        if (i == 10) top->rst_n = 1;
    }

    top->final();
    tfp->close();
    delete top;
    delete tfp;
    return 0;
}
```

Key methods:
- `top->eval()` — evaluates the circuit (must call after changing inputs)
- `top->trace(tfp, depth)` — enable tracing
- `tfp->dump(time)` — write current state to waveform
- `top->final()` — cleanup
